# 界面设计

风格简洁，标签和说明尽量短。常用状态与操作直接可见，高级配置和原始数据按需展开。两端共享业务规则，分别使用宿主主题与原生能力。

## Pi TUI

`/pbot` 打开菜单，原有子命令仍可直接使用。菜单支持键盘选择和长列表滚动；状态、历史及公共消息使用只读阅读页。专家仍通过 tmux 进入原生会话。后台提示最多显示四位专家。

## dsh GUI

工作台分工作区、专家、团队、历史四页。宽窗口使用侧边导航，窄窗口使用顶部导航与单列布局。专家列表支持筛选；表单、记录和高级设置分开呈现。查询与提交显示各自结果，不把任务排队当作完成。

轮询保留表单草稿、输入焦点和分页。关闭取消查询及未接纳上传；已接纳操作归服务端。查看页面不恢复专家、不领取模型通知。
