# Python 计算

## 运行方式

通过当前宿主的原生 Bash，沿用项目声明的解释器、依赖、工作目录、入口和输出位置。尚无约定时，先检查可用解释器和所需库再执行。

包内相对导入在项目根目录用 `python -m 包.模块`，不靠改 `sys.path` 绕过导入错误。交付时核对结果并给出实际产物路径。

解释器或依赖异常时，检查实际路径、导入错误与项目配置，继续不受影响的工作；专家需要主会话协助时交回具体阻碍和所需条件。

## 常见约束

- 无图形界面绘图：导入 `pyplot`/`seaborn` 前设置 Matplotlib `Agg` 后端，保存文件后关闭 figure。
- 表格与二进制文件（Excel/Parquet/Feather）：核对读写后的字段类型、时间单位与时区；Excel 不直接保存带时区的 `datetime`，转换前先确定目标时区。
- 统计与建模：记录数据口径和假设；时间序列按时间切分，预处理只在训练集拟合，避免未来数据泄漏。
- 技术指标或回测：另读同目录 [compute-finance.md](compute-finance.md)，显式确定数据口径和交易假设。
