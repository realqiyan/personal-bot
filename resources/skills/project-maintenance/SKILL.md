# 项目整理与维护

让资料呈现当前结论、适用条件、分析口径和未决问题。重要结论或决策变化保留原因与原依据。

根据本次变化更新当前任务、所属正文及实际受影响的引用。整体整理按用户指定范围进行。

## 更新所属资料

从根 AGENTS.md 和相关目录入口定位正文；入口未命中时，按主题、别名或项目名搜索。结合实际成果核对正文与入口，资料状态以对应证据为依据。

按主题合并当前说明，保留理解、继续或复用任务所需的信息。新旧证据先核对对象、时期和条件；用已确认的新结论替换被取代的说明，同步相关说明与引用，保留未解决的冲突。

历史证据与重要决策保留原有来源、时点、适用条件及必要理由，当前说明通过引用追溯。用户偏好与约束按其确认范围记录，推断与已确认约定分开。

从项目结论中提炼可跨任务复用的概念、方法与口径，写入 knowledge/，说明适用条件并引用来源。知识按主题命名，需要保留历史的研究和决策按日期与主题命名。

尊重根 AGENTS.md 已有的导航格式和工作区约定，只更新受本次变化影响的入口，不为统一样式重排。新建导航时可用 text 目录树，展开到有资料的主题或项目目录并简注用途，也可按已有习惯使用链接列表；任务状态沿用现有标记。结论和未决事项留在正文，导航引用对应资料。

## 复用任务定义

需要跨会话继续或重复执行的任务，在所属项目或长期事务中保存交付用途、必要证据、可接受限制和完成条件。目标变化时同步受影响的交付条件。

重复分析或报告的定义按需包含数据来源与查询方式、对象与筛选范围、期间与时区、单位、指标公式与分母、分组与比较基准、执行入口及核验条件。单次报告引用所用定义。

按上次口径重做时，读取已有定义，沿用已确认选择，并核对来源、版本与关键前提是否仍适用。更新报告使用本次期间与数据；复现历史结果使用指定输入。口径变化说明对可比性的影响，验证状态随新的验证证据更新。

## 成果归集与清理

用户要求整理或结项时，检查本次范围内的项目目录及 scratch/ 等临时产物位置。将结论与方法并入所属正文，将交付物与可复用源码归入对应项目，更新来源引用与执行入口。

归集后清理本次范围内已被正文吸收或不再需要的临时文件。正式资料、历史记录与备份保持原样。

## 项目结项

以已确认的目标和交付条件判断完成状态，核对交付物、来源引用与执行入口确实可用。满足本次用途即可结项，已知限制留在正文；可选深化与必需工作分开。

交付条件尚未满足时，记录具体缺口及其影响。完成状态、正文与证据一致后，同步项目入口和相关导航。
