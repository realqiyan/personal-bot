# 项目整理与维护

让资料呈现当前结论、适用条件、分析口径和未决问题。重要结论或决策变化时简要说明原因。

根据本次变化更新当前任务、所属正文及实际受影响的引用。整体整理按用户指定范围进行。

## 更新所属资料

从根 AGENTS.md 和相关目录入口定位正文；入口未命中时，按主题、别名或项目名搜索。

按主题合并当前说明，保留继续或复用任务所需的信息。比较新旧内容的对象、时期和条件，替换过时说明，同步引用，保留未解决的冲突。

保留历史资料与重要决策的来源和时间，当前说明通过引用连接。用户偏好与约定按用户表达记录，不把推测写成既定约定。

从项目结论中提炼可跨任务复用的概念、方法与口径，写入 knowledge/，说明适用条件并引用来源。知识按主题命名，需要保留历史的研究和决策按日期与主题命名。

尊重根 AGENTS.md 已有的导航格式和工作区约定，只更新受本次变化影响的入口，不为统一样式重排。新建导航时可用 text 目录树，展开到有资料的主题或项目目录并简注用途，也可按已有习惯使用链接列表；任务状态沿用现有标记。结论和未决事项留在正文，导航引用对应资料。

## 复用任务定义

需要跨会话继续或重复执行的任务，在所属项目或长期事务中保存目标、输入、执行方式和预期产物，随任务变化更新。

重复分析或报告的定义按需包含数据来源与查询方式、对象与筛选范围、期间与时区、单位、指标公式与分母、分组与比较基准、执行入口。单次报告引用所用定义。

按上次口径重做时，读取已有定义，检查来源、版本与关键前提是否仍适用。更新报告使用本次期间与数据；复现历史结果使用指定输入。口径变化说明对可比性的影响。

## 成果归集与清理

用户要求整理或结项时，检查本次范围内的项目目录及 scratch/ 等临时产物位置。将结论与方法并入所属正文，将交付物与可复用源码归入对应项目，更新来源引用与执行入口。

归集后只清理本次范围内已被正文吸收或不再需要的临时文件，不删除正式资料、历史记录或备份。

## 项目结项

按任务目标检查交付物和执行入口。满足本次用途即可结项；尚有缺口时说明剩余工作，额外建议另列。更新项目状态和相关导航，已知限制留在正文。
