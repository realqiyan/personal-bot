# 项目整理与维护

让资料呈现当前结论、适用条件、必要证据和真正未决的问题。重要结论或决策变化保留原因与原依据。

根据本次变化更新当前任务、所属正文及实际受影响的引用。整体整理按用户指定范围进行。

## 更新所属资料

从根 AGENTS.md 和相关目录入口定位正文；入口未命中时，按主题、别名或项目名搜索。结合实际成果核对正文与入口，资料状态以对应证据为依据。

按主题合并当前说明，保留理解、继续或复用任务所需的信息。新旧证据先核对对象、时期和条件；用已确认的新结论替换被取代的说明，同步相关说明与引用，保留未解决的冲突。

历史证据与重要决策保留原有来源、时点、适用条件及必要理由，当前说明通过引用追溯。用户偏好与约束按其确认范围记录，推断与已确认约定分开。

有跨任务价值的知识提炼到 knowledge/ 并引用项目证据，保留复用所需的条件。知识按主题命名，需要保留历史的研究和决策按日期与主题命名。

尊重根 AGENTS.md 已有的导航格式和工作区约定，只更新受本次变化影响的入口，不为统一样式重排。新建导航时可用 text 目录树，展开到有资料的主题或项目目录并简注用途，也可按已有习惯使用链接列表；任务状态沿用现有标记。结论和未决事项留在正文，导航引用对应资料。

## 复用任务定义

需要跨会话继续或重复执行的任务，在所属项目或长期事务中保存交付用途、必要证据、可接受限制和完成条件。目标变化时同步受影响的交付条件。

重复分析或报告的定义按需包含指标公式与分母、数据来源、对象与筛选范围、期间与时区、分组与比较基准、输入和执行入口、产物位置及核验条件。单次输入与结果作为有时点的证据引用，与可复用定义分开。

按上次口径重做时，读取已有定义，沿用已确认选择，并核对来源、版本与关键前提是否仍适用。更新报告使用本次期间与数据；复现历史结果使用指定输入。口径变化说明对可比性的影响，验证状态随新的验证证据更新。数值与计算核验见 [analysis-validation 技能](../analysis-validation/SKILL.md)。

## 成果归集与清理

用户要求整理或结项时，检查本次范围内的项目目录及 scratch/ 等临时产物位置。将有用信息并入正文，将必要证据与复现资料保存到对应 projects/<名称>/。

长期保留支撑结论的最小充分资料：

- 无法可靠恢复的输入快照、来源与数据口径。按能否再次取得同一份输入判断保存价值，而非来源是否仍可访问。
- 复现所需的源码、命令、参数、必要环境说明及结果引用；数据注明对象、时点与单位。
- 用户要求的最终成果与明细。

完成归集并更新引用和复现路径后，清理已被吸收或不再需要、且不承担证据作用的临时产物。仍在使用、跨项目共享或归属与价值不明的文件暂留。清理仅限本次范围内的临时产物；正式资料、历史交易记录与备份保留，历史记录不改写。

## 项目结项

以已确认的目标和交付条件判断完成状态，核对必要成果、证据与复现入口确实可用。满足本次用途即可结项，已知限制留在正文；可选深化与必需工作分开。

交付条件尚未满足时，记录具体缺口及其影响。完成状态、正文与证据一致后，同步项目入口和相关导航。
