# 分析核验

围绕本次要支持的结论，优先核验足以改变判断的数据和计算。检查范围随结论风险和已发现的问题确定。

## 确定核验依据

读取已有结论及其实际数据、公式、源码和参数，确认对象范围、样本单位、比较基准和关键假设。缺少原始数据或计算入口时，区分能验证的部分与只能检查说明的部分。

## 数据完整性与含义

- 核对筛选、分页、截断及对象和期间覆盖。总量以已确认的覆盖范围为限；空结果能否支持“不存在”的判断，取决于查询覆盖。
- 区分已确认零值、缺失、未查询、不可用和查询失败，按字段定义解释空值与零。
- 汇总与明细不符时，先对齐期间、范围与定义。只有范围一致且明细完整时，明细重算才可验证汇总；冲突无法解释时保留两者与影响。
- 按样本单位检查缺失、重复和关联前后的数量，区分同一对象的不同观测与重复计数。

根据来源定义、时间语义和指标性质判断字段值是否异常，修正需有依据。

## 口径与计算

按任务选择能暴露错误的检查：

| 对象 | 检查方法 |
| --- | --- |
| 比例与平均数 | 核对分子分母对应的对象与期间；分母为零时说明不可计算；分组平均按适当权重合并 |
| 分项与总数 | 确认可加性，核对合计与差异；重叠分类、不同币种和非加性指标不能直接求和 |
| 时间比较 | 对齐期间长度、完整程度与时区；区分数据发生时间和当时实际可获得时间 |
| 单位与市场口径 | 核对币种、数量单位、复权和费用假设；转换需有依据，不隐含换算或市场规则 |
| 关键计算 | 独立复算影响结论的值，或抽查原始记录与边界；只重跑同一段源码不能排除同一逻辑错误 |
| 图表 | 核对图表与底层数据、标注、尺度及比较范围，避免显示方式改变读者判断 |

输入或口径变化时，说明对可比性和结论的影响。复算依据保留实际命令、参数、必要输入与结果引用。

## 推断与适用限制

结论涉及样本推广、原因解释或预测时，检查样本选择与排除条件、样本量、幸存者偏差、替代解释和不确定性。多次比较、试验或参数筛选需结合完整选择过程评估结果。

时间序列或预测研究需要核对信息在当时是否可知、训练与评估是否泄漏。样本外检验、成本和成交约束按研究用途确定；条件未验证时限制结论范围，不把库默认值当成实际市场条件。

若主要问题是来源冲突或证据不足，使用 [research-evidence 技能](../research-evidence/SKILL.md) 处理相应判断。

## 交付核验结论

说明实际核验范围、发现的问题及其对结论的影响，判断结果足以支持本次用途、带限制可用，还是需要修正。指出关键缺口、适用条件与尚未核验的部分；修正后复查受影响结论。
