# 分析核验

从本次要支持的结论选择检查，优先处理会改变判断的错误。简单计算可直接核对关键值；复杂分析按实际风险扩大范围，不机械执行全部检查或要求另写核验报告。

## 确定核验依据

读取已有结论及其实际数据、公式、源码和参数。核对对象范围、样本单位、统计期间、单位、币种、比较基准和关键假设。缺少原始数据或计算入口时，区分能验证的部分与只能检查说明的部分。

能力提供方手册用于理解字段，参数和结果以原生 CLI 帮助或 MCP 定义为准。工具摘要或结果预览不代表完整数据，必要时读取已保存正文，不为取得旧结果重新发送原调用。

## 数据完整性与含义

- 核对分页、筛选、前 N 条、截断预览、覆盖市场与统计期间。无法证明完整时，把总量标为已取得范围内的数值，不当成总体。
- 区分已确认零值、缺失、未查询、不可用和查询失败。按字段约定判断空值与零，不仅凭看起来不合理就改值、填零或删除记录。
- 对空结果核对请求条件与可取得的覆盖依据。没有查到订单、活动或记录，不足以证明它从未发生。
- 汇总与明细不符时，先核对两者的期间、范围、分页与定义。只有范围一致且明细完整时，明细重算才可用于验证汇总；冲突无法解释时保留两者与影响。
- 检查缺失样本、重复记录和关联前后的数量。区分同一对象的不同观测与重复计数；不能靠无依据的去重掩盖关联错误。

## 口径与计算

按任务选择能暴露错误的检查：

| 对象 | 检查方法 |
| --- | --- |
| 比例与平均数 | 核对分子分母对应的对象与期间；分母为零时说明不可计算；分组平均按适当权重合并 |
| 分项与总数 | 确认可加性，核对合计与差异；重叠分类、不同币种和非加性指标不能直接求和 |
| 时间比较 | 对齐期间长度、完整程度与时区；区分数据发生时间和当时实际可获得时间 |
| 单位与市场口径 | 核对币种、数量单位、复权和费用假设；转换需有依据，不隐含换算或市场规则 |
| 关键计算 | 独立复算影响结论的值，或抽查原始记录与边界；只重跑同一段源码不能排除同一逻辑错误 |
| 图表 | 核对图表与底层数据、标注、尺度及比较范围，避免显示方式改变读者判断 |

数据时区标注与时间偏移冲突时，按来源定义核实，不能静默选择。未来日期可能是预约、到期或预测，只有不符合字段含义时才视为异常。数值范围也依指标判断，增长率不能套用占比的范围。

输入或口径变化时，确认比较仍有效并记录差异。为当前核验运行计算时保留实际命令、参数、必要输入与结果引用；不覆盖已有研究证据来消除差异。

## 推断与适用限制

结论涉及样本推广、原因解释或预测时，检查样本选择与排除条件、样本量、幸存者偏差、替代解释和不确定性。多次比较、试验或参数筛选应说明选择过程，不能只展示支持原假设的结果。

时间序列或预测研究需要核对信息在当时是否可知、训练与评估是否泄漏。样本外检验、成本和成交约束按研究用途确定；条件未验证时限制结论范围，不把库默认值当成实际市场条件。

若主要问题是来源冲突或证据不足，使用 [research-evidence 技能](../research-evidence/SKILL.md) 处理相应判断。

## 交付核验结论

说明实际检查、发现的问题、受影响结论及未完成检查，按本次用途判断：

- 足以支持本次用途：关键依据与计算已核对，没有发现阻止交付的问题。
- 带限制可用：明确哪些结论成立、依赖哪些条件、哪些用途尚不支持。
- 需要修正：指出具体错误或关键缺口，以及修正或核实后需重查的部分。

修正后重查受影响结论；检查通过后，仅因新修改、失败或未决疑点扩大检查。分析质量判断不代表业务操作已获许可，也不能代替交易方案复核或调用批准。
